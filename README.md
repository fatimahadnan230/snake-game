# 🐍 Pastel Snake (Macaron Muncher) ✨

A retro arcade classic redesigned with a cozy pastel aesthetic, smooth grid-based movement, and sound effects built using the Web Audio API. Crafted for the Game Development Society!

## 🎮 Features
* **Cozy Theme:** Soft pink snake body, purple treats, and a grid background styled with Tailwind CSS.
* **Responsive Controls:** Fully playable using Arrow Keys or WASD keys.
* **Persistent High Scores:** Automatically saves your personal best record using browser `localStorage`.
* **Sound Effects:** Retro-inspired audio synthesized entirely inside the browser without any external audio files.

## 🚀 Built With
* **HTML5 Canvas & JavaScript**
* **Tailwind CSS**

## 🕹️ How to Play
* Use your keyboard arrow keys or `W`, `A`, `S`, `D` to steer the snake.
* Eat the purple treats to score points and grow longer.
* Avoid running into the walls or hitting your own tail!
